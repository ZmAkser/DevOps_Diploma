# Итоговый проект курса «DevOps-инженер с нуля»
## Автор проекта - Мелетьев Роман Андреевич

Проект представляет собой тестовую веб страницу, работающую на nginx в docker-контейнере.
Виртуальная машина разворачивается на Yandex Cloud при помощи связки Terraform + Ansible.
Конфигурация Terraform сохраняется в Yandex ObjectSorage S3 bucket.
Докер контейнеры сохраняются и скачиются в Yandex Container Registry.
CI/CD пайплайн для автоматической доставки изменений на ВМ реализован в Github Actions.

### Для запуска проекта нужно произвести следующие действия:

#### 1. Подготовка рабочего места, с короторого будет выполняться развертывание проекта

    1.1 Зарегистрируйтесь в Yandex Cloud и создайте там S3 хранилище и реестр в Container Registry.
    1.2 Создайте сервисный аккаунт, при помощи которого будем взаимодействовать с ресурсами Яндекса. Для простоты настройки выдайте этому аккаунту роль editor.
    1.3 Создайте для этого аккаунта авторизованный ключ(обязательно сохраните json файл ключа) и статический ключ доступа(сохраните пару ключей на свой ПК).
    1.4 Выполните в терминальной сесии следующие команды, либо настройте их автоматические выполнение например через файл ~/.bashrc :

    - export TF_VAR_cloud_id="идентификатор вашего облака Яндекс"
    - export TF_VAR_folder_id="идентификатор вашего рабочего каталога в облаке"
    - export AWS_ACCESS_KEY_ID="ID вашего статического ключа доступа(из п.1.3)"
    - export AWS_SECRET_ACCESS_KEY="ваш статический ключ доступа(из п. 1.3)"

    1.5 Сгенирируйте пару SSH ключей для вашей машины.
    1.6 Зарегистрируйтесь на Github и создайте пустой репозиторий, через который будет происходить доставка кода до ВМ.
    1.7 Создайте пустой каталог и сделайте в него клон репозитория проекта командой git clone https://github.com/ZmAkser/DevOps_Diploma.git 
    1.8 Установите на ваш компьютер Terraform(1.16.0 или выше) и Ansible.

#### 2 Создание инфраструктуры в Yandex Cloud

    2.1 Перейдите в каталог terraform
    2.2 Разместите ваши json-файл из п. 1.3 и публичный ssh ключ по путям, указанным  файлах проекта или измените путь на нужный вам.
    2.3 Последовательно выполните команды terraform init terraform plan terraform apply.
    2.4 Зайдите в ваш Yandex Cloud, там появится готовая к работе ВМ, сохраните её внений IP адрес.

#### 3 Настройка ВМ для запуска Docker контейнера

    3.1 Перейдите в каталог ansible.
    3.2 В файле hosts.ini укажите IP адрес вашей ВМ из п. 2.4.
    3.3 Выполните команду ansible-playbook install-docker.yaml
    3.4 Скорируйте ваш json-файл на машину при помощи SCP
    3.5 Подключитесь к машине по SSH командой "ssh ubuntu@адрес_вашей_машины"
    3.6 Выполните на машине команду cat "путь_к_вашему_json_файлу" | docker login cr.yandex -u json_key --password-stdin для авторизации в Yandex Container Registry

#### 4 Настройка CI/CD на Github

    4.1 Выполните клонирование вашего репозитория из п. 1.6 в пустой каталог на вашей машине.
    4.2 Скопируйте все содержимое папки docker в этот каталог
    4.3 Для корректной работы необходимо задать секреты в вашей репозитории на Github. По пути Setting - Secrets and variables - Actions 
    создайте следующие Repository secrets:

    - YCR_JSON_KEY    Все содержимое вашего json файла из п. 1.3
    - SSH_HOST        IP вашей ВМ из п. 2.4
    - SSH_USER        ubuntu
    - SSH_PRIVATE_KEY Ваш приватный SSH ключ

    4.4 Синхронизируйте содежимое вашей локальной папки с репозиторием(git add git commit git push)
    4.5 С этого момента любые изменения в файле index.html из папки html, которые вы загрузите в репозиторий будут автоматически доставлятся на ВМ

#### 5 Проверка работоспобности

    В браузере перейдите по адресу http://ip_вашей_вм:8080 либо выполните curl http://ip_вашей_вм:8080
